# 华东师范大学 珍木科研园 · 一树一码

本站点用于展示珍木科研园珍稀树木的监测记录与科普信息，为纯静态网站（HTML / CSS / JavaScript），通过 GitHub Pages 发布。

## 内容说明

- 5 个树种、20 株树木的监测记录展示
- 树种科普介绍与单株监测数据
- 一树一码二维码页面
